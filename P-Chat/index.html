答疑

常见问题

关于 P Chat 的疑问，在这里找到答案。

需要注册账号吗？

不需要。P Chat 无账号、无密码，打开即用。故事、角色与配置全部保存在设备本地，卸载即彻底删除。

我的 API Key 安全吗？

安全。Key 使用 iOS Keychain 加密存储，仅保存在你的设备上。对话请求由设备直连你配置的服务商，我们没有任何中间服务器。你还可以在设置中一键关闭全部网络请求。

支持哪些 AI 模型？

内置 DeepSeek、OpenAI、Anthropic Claude、Google Gemini、xAI Grok 与豆包（火山方舟）预设，也支持任何 OpenAI 兼容的自定义接口；每个服务商可维护自己的模型列表，并支持深度思考（推理）模式。

故事模式和群聊角色扮演有什么区别？

故事模式：由「故事导演」AI 逐幕推进的单人剧情，你以角色身份回应，也能切换为导演旁白。

群聊演绎：最多 8 位角色同台，五种发言策略决定谁接话，适合多人互动的长线剧情。

什么是剧情记忆？

App 会自动生成前情摘要，你也可以维护长期记忆列表并一键总结。这样即使故事很长、超出上下文窗口，角色依然记得重要的事。

如何删除我的数据？

设置中提供本机数据统计与一键清空；删除单个故事或角色也会同步清理其数据。卸载 App 即彻底删除全部内容。
