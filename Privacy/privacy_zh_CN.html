隐私政策

本政策适用于 Suzatei 开发的应用程序，包括 API 钱包（API Wallet）、P Chat 与 PhoenixAI，以及我们未来发布的其他应用。

最后更新：2026 年 9 月 12 日

我们的承诺

我们深知个人信息对您的重要性，并对您的数据抱以最高程度的尊重。在 Suzatei，隐私保护不是事后补救，而是产品设计的起点。我们遵循以下基本原则：

  • 本地优先：您的内容默认保存在您自己的设备上，而不是我们的服务器；
  • 最小化收集：能不收集的数据一律不收集，必须处理的数据坚持最小必要范围；
  • 绝不牟利：我们不出售您的个人数据，不将其用于跨应用广告追踪，也不与第三方共享用于其自身的营销目的；
  • 公开透明：我们收集什么、为什么收集、如何使用，都会在本政策中如实说明，并随产品发展持续更新。

当前的数据收集情况

截至本政策更新之日，我们的应用在设计上不收集、不传输、不共享任何个人数据：应用内不含统计分析、广告或追踪组件，我们的服务器亦不接收您的任何数据。您的全部内容仅保存在您的设备本地。

未来可能收集的信息

随着产品持续迭代，为了解应用运行状况、排查故障并不断提升产品质量与使用体验，我们可能在未来版本中收集有限的、以改进产品为唯一目的的信息，例如：

  • 匿名化或聚合的使用统计：如功能使用频次、页面访问情况等汇总数据，通常无法识别您的身份；
  • 诊断与技术信息：如设备型号、操作系统版本、应用版本、语言或地区设置、崩溃日志等，用于定位和修复问题；
  • 您主动提供的内容：当您通过电子邮件等渠道向我们反馈问题或建议时，我们会使用您提供的信息回复并改进产品。

上述信息仅用于 Suzatei 内部的产品改进、质量评估与服务优化，不会用于广告，不会出售，也不会与第三方共享用于其自身的营销目的。在实际开始收集前，我们会通过应用内公告或更新本政策等方式提前告知，并在适用法律要求的范围内事先征得您的同意。

您配置与创建的内容

您在使用我们的应用过程中配置或创建的以下内容，均保存在您的设备本地：

  • API 密钥：使用操作系统提供的系统钥匙串（Keychain）加密存储，仅存在于您的设备；
  • 对话、故事、角色与设置：存储在设备本地的应用沙盒中；
  • 生成的图片与视频：存储在设备本地的应用沙盒中，仅在您主动操作时保存到相册或对外分享；
  • 服务商余额缓存：存储在设备本地的应用沙盒与小组件共享容器中，用于展示。

这些数据由您全权掌控：您可以随时在应用内查看、导出或删除它们。

数据的存储与安全

我们采取多种措施保护您的数据安全：敏感凭据（如 API 密钥）使用系统级加密机制（Keychain）保存；应用数据存储于操作系统沙盒内，其他应用无法访问；涉及网络传输的请求均使用 HTTPS 加密通道。我们的应用不依赖自建服务器存储您的数据，因此不存在我们侧的数据库泄露风险。我们也会持续关注安全最佳实践，并在产品迭代中不断加固。

网络请求

仅在您主动执行操作时（例如查询余额、发送对话、生成图片或视频），应用会从您的设备直接向您自行配置的第三方服务（如各 AI 服务商的官方 API）发起 HTTPS 请求，并携带您保存的密钥用于身份验证。

除上述由您发起的请求外，应用不会与任何服务器通信。我们无法、也无权访问这些第三方服务，以及请求的发起过程与返回内容。部分应用还提供联网总开关，您可一键切断应用的全部网络请求。

第三方服务

您自行配置并使用的第三方 AI 服务受该服务提供方各自的隐私政策与条款约束，请自行查阅。您向第三方服务发送的内容（包括提示词、对话与素材）由该第三方按照其自身政策处理，Suzatei 对第三方服务的数据处理行为不承担责任。

未成年人保护

我们的应用不面向 13 岁以下的儿童，我们也不会有意收集儿童的个人信息。如果您认为有儿童向我们提供了个人信息，请通过下文方式联系我们，我们将及时处理并删除相关数据。

您的权利

您对自己的数据拥有完整的控制权：

  • 访问与控制：您的数据均存储在设备本地，您可随时在应用内查看、全屏预览、保存到相册或分享；
  • 删除：您可以在应用内删除单个项目，或使用一键清空功能清除全部本机数据；卸载应用即彻底删除全部本地数据，我们不会留存任何副本；
  • 疑问与投诉：如对本政策的执行有任何疑问，或希望行使上述权利，请通过下文方式联系我们，我们会尽快回复。

政策变更

随着产品与法律法规的发展，本政策可能不时更新。发生变更时，我们将在本页面发布更新并标注"最后更新"日期；若变更涉及您的重大权益，我们会以更显著的方式提示您。建议您定期查阅本页面了解最新内容。
