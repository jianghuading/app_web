FAQ

Frequently Asked Questions

Answers to common questions about API Wallet.

How do I get an API key?

Create one in each platform's console, under the API Keys page:

DeepSeek: platform.deepseek.com; OpenAI: platform.openai.com; Anthropic Claude: console.anthropic.com; Kimi: platform.moonshot.cn; Zhipu: bigmodel.cn. Then pick the provider in API Wallet, paste your key and save.

Are my API keys safe?

Yes. Keys are encrypted in the iOS Keychain and stay on your device. The app uploads no keys or balance data to any server of ours — every request goes straight from your device to each platform's official API.

Deleting a configuration also deletes its key from the Keychain.

How do I add the home-screen widget?

Long-press the home screen → tap “+” → search for “API Wallet” → pick a size. Then long-press the widget → “Edit Widget” to choose which providers appear.

Note: run one balance query in the app first so the widget has data to show. The system refreshes widgets roughly every 30 minutes.

Can I add multiple keys for one provider?

Yes. Add as many keys per provider as you like — a personal and a company account, for example — and tell them apart with notes shown next to the name.

How often do balances refresh?

Opening the app or pulling to refresh queries every provider instantly. You can also set a per-provider auto-refresh interval (active while the app is in the foreground).

Can I query custom or relay endpoints?

Choose “Custom API” from the “+” menu on the home screen, enter the base URL and an optional API key, then write a query script. Variable substitution is supported, and “Test Query” verifies everything before you save.

How do I delete my data?

Deleting a provider configuration removes its key from the Keychain. Uninstalling the app wipes all local data — nothing is left behind.
